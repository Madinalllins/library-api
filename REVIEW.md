# Саморевью API-контракта

## Ресурсы и URL

- [x] Ресурсы названы существительными во множественном числе: `/books`, `/readers`, `/loans`.
- [x] В URL нет глагольных названий, кроме осознанного действия `/loans/{id}/return`.
- [x] Идентификатор конкретного ресурса передаётся в path.
- [x] Фильтры, сортировка и пагинация передаются через query-параметры.
- [x] Версия API `/v1` указана в `servers`.
- [x] В URL используется kebab-case.
- [x] В JSON используется snake_case.

## Методы и HTTP-коды

- [x] Для Books и Readers описаны CRUD-операции.
- [x] Для Loans описаны создание, список, получение по id и возврат.
- [x] Создание ресурса возвращает `201` и заголовок `Location`.
- [x] Удаление возвращает `204` без тела ответа.
- [x] Пустой список возвращается с кодом `200`, а не `404`.
- [x] Отсутствующий ресурс возвращает `404`.
- [x] Конфликт состояния или бизнес-правила возвращает `409`.
- [x] Ошибка проверки данных возвращает `422`.

## Схемы данных

- [x] Описаны схемы Book, Reader и Loan.
- [x] Схемы запросов отделены от схем ответов.
- [x] Серверные поля не принимаются от клиента.
- [x] Поле `available_copies` имеет `readOnly: true`.
- [x] `available_copies` вычисляется из `total_copies` и активных выдач.
- [x] Поле `returned_at` допускает `null`.
- [x] Неизвестные поля запросов запрещены через `additionalProperties: false`.
- [x] Типы, обязательные поля и ограничения указаны явно.

## Ошибки и списки

- [x] Все ошибки используют единый `ErrorResponse`.
- [x] Описаны коды `INVALID_REQUEST`, `NOT_FOUND`, `VALIDATION_ERROR`, `CONFLICT`, `BUSINESS_RULE_VIOLATION` и `IDEMPOTENCY_MISMATCH`.
- [x] Ответ об ошибке содержит стабильный код и `request_id`.
- [x] Для ошибки `422` приведён пример с `details`.
- [x] Коллекции поддерживают фильтры, сортировку и пагинацию.
- [x] Параметр `limit` имеет значение по умолчанию `20` и максимум `100`.
- [x] Просроченные выдачи запрашиваются через `GET /loans?status=overdue`.

## Бизнес-правила и идемпотентность

- [x] Выдача разрешена только при `available_copies > 0`.
- [x] У читателя может быть не более пяти активных выдач.
- [x] `due_date` новой выдачи должна быть позже текущей даты.
- [x] Книгу или читателя нельзя удалить при наличии активных выдач.
- [x] Возврат выполняется через `POST /loans/{id}/return`.
- [x] Для `POST /loans` обязателен `Idempotency-Key`.
- [x] Описан полный повтор исходного ответа.
- [x] Для того же ключа и другого тела описан `IDEMPOTENCY_MISMATCH`.
- [x] Описано поведение конкурентных повторных запросов.
- [x] Срок хранения ключа составляет 24 часа.

## Документация

- [x] Используются теги Books, Readers и Loans.
- [x] Ключевые операции имеют `summary` и `description`.
- [x] Общие схемы подключаются через `$ref`.
- [x] Добавлены примеры успешных ответов и типичных ошибок.
- [x] В `STYLE.md` записаны правила проектирования API.
- [x] В `README.md` описаны назначение и структура проекта.
