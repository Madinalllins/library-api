# Library API

Домашнее задание по проектированию API-контрактов.

Проект содержит контракт OpenAPI 3.1 для сервиса «Библиотека». Контракт описывает управление книгами, читателями и выдачами книг.

## Состав проекта

- `openapi.yaml` — контракт OpenAPI 3.1
- `STYLE.md` — правила проектирования API
- `REVIEW.md` — саморевью по чек-листу
- `README.md` — описание проекта

## Ресурсы

### Books

Ресурс `/books` поддерживает создание, получение, полное обновление и удаление книг.

Поле `available_copies` вычисляется сервером на основании общего количества экземпляров и активных выдач. Клиент не передаёт это поле.

### Readers

Ресурс `/readers` поддерживает регистрацию, получение, полное обновление и удаление читателей.

Читателя нельзя удалить, если у него имеются активные выдачи.

### Loans

Ресурс `/loans` поддерживает создание и просмотр выдач.
